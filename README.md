# Visual Studio Projects & QA Test Suites

A collection of academic projects focused on software testing automation, quality assurance, and object-oriented programming in C++.
## Included Projects

### 1) CentricTester
A testing suite designed to validate various operational scenarios, edge cases, and functional requirements based on QA training at Centric.

### 2) G2A Search Automation (`G2A_SearchTest`)
Automated test suite targeting the search functionality of **G2A.com** using C# Selenium WebDriver

### 3) Company Management System (`Proiect_POO`)
A terminal-based program implementing object-oriented programming concepts (encapsulation, inheritance, polymorphism) to manage organizational structures, departments, and employee data.
